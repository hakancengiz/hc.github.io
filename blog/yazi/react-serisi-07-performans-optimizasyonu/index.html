React performansını artırmak için temel olarak şu üç konuyu bilmek gerekiyor:

  1. Gereksiz render’ları önlemek
  2. Hook’ların doğru kullanımı (memo, useMemo, useCallback)
  3. Büyük listeleri ve componentleri optimize etmek

1. Gereksiz Render’ların Tespiti

React her state değişiminde ilgili component’i yeniden render eder.
Ama bazı durumlarda gereksiz render performansı düşürür.

import React, { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  console.log("Counter render oldu"); // Her render’da konsola yazılır

  return (
    <div>
      <h2>Sayaç: {count}</h2>
      <button onClick={() => setCount(count + 1)}>Artır</button>
    </div>
  );
}

function App() {
  return (
    <div>
      <Counter />
      <Counter />
    </div>
  );
}

export default App;
Bu örnekte bir Counter güncellendiğinde diğer Counter da render olur. Gereksiz render’ı engellemek için React.memo kullanacağız.

2. React.memo ile Component Optimizasyonu

React.memo, props değişmediyse component’in yeniden render edilmemesini sağlar.

import React, { useState, memo } from "react";

const Counter = memo(({ value }) => {
  console.log("Counter render oldu:", value);
  return <h3>{value}</h3>;
});

function App() {
  const [count1, setCount1] = useState(0);
  const [count2, setCount2] = useState(0);

  return (
    <div>
      <button onClick={() => setCount1(count1 + 1)}>Sayaç 1 Artır</button>
      <button onClick={() => setCount2(count2 + 1)}>Sayaç 2 Artır</button>

      <Counter value={count1} />
      <Counter value={count2} />
    </div>
  );
}

export default App;

Artık bir sayaç değiştiğinde, diğer sayaç yeniden render olmaz.

3. useMemo ile Hesaplama Optimizasyonu

Bazen bir component içinde ağır hesaplamalar olabilir.
 useMemo, bu hesaplamayı state veya props değişmediğinde tekrar çalıştırmaz.

import React, { useState, useMemo } from "react";

function App() {
  const [count, setCount] = useState(0);
  const [text, setText] = useState("");

  // Ağır hesaplama simülasyonu
  const factorial = useMemo(() => {
    console.log("Hesaplama yapıldı");
    const calc = (n) => (n <= 1 ? 1 : n * calc(n - 1));
    return calc(count);
  }, [count]); // Sadece count değişirse yeniden hesaplanır

  return (
    <div>
      <h2>Faktöriyel: {factorial}</h2>
      <button onClick={() => setCount(count + 1)}>Artır</button>
      <input
        type="text"
        value={text}
        onChange={(e) => setText(e.target.value)}
        placeholder="Bir şey yaz..."
      />
    </div>
  );
}

export default App;

Input değişse bile ağır hesaplama tekrar çalışmaz, performans artar.

4. useCallback ile Fonksiyon Optimizasyonu

Child component’e props olarak fonksiyon gönderirken, fonksiyon her render’da yeni referans oluşturur.
Bunu useCallback ile engelleyebiliriz.

import React, { useState, useCallback, memo } from "react";

const Button = memo(({ onClick, label }) => {
  console.log("Button render:", label);
  return <button onClick={onClick}>{label}</button>;
});

function App() {
  const [count, setCount] = useState(0);

  // useCallback: fonksiyon referansı değişmez
  const increment = useCallback(() => setCount((c) => c + 1), []);

  return (
    <div>
      <h2>Sayaç: {count}</h2>
      <Button onClick={increment} label="Artır" />
    </div>
  );
}

export default App;

Böylece Button component’i gereksiz yere render olmaz.

5. Büyük Listelerde Optimizasyon

Büyük listeler render edilirken yavaşlama olabilir.
 react-window veya react-virtualized kütüphaneleri ile sadece görünürdeki öğeler render edilir.

npm install react-window
import { FixedSizeList as List } from "react-window";

const data = Array.from({ length: 1000 }, (_, i) => `Öğe ${i + 1}`);

function App() {
  return (
    <List
      height={300} // Görüntü yüksekliği
      itemCount={data.length} // Liste uzunluğu
      itemSize={35} // Her öğe yüksekliği
      width={300}
    >
      {({ index, style }) => <div style={style}>{data[index]}</div>}
    </List>
  );
}

export default App;

1000 öğelik listeyi performanslı şekilde render ettik.

6. React Profiler ile Performans Analizi

React Developer Tools içinde bulunan Profiler, component’lerin render sürelerini ölçer.

  • Her render ne kadar sürdü?
  • Hangi component gereksiz yere render oldu?
  • Memo veya useMemo ile optimizasyon gerekiyor mu?

Özet

| Konu               | Açıklama                                                              |
| ------------------ | --------------------------------------------------------------------- |
| **React.memo**     | Props değişmediğinde component’in render olmamasını sağlar            |
| **useMemo**        | Ağır hesaplamaları cache’ler, gereksiz tekrarları önler               |
| **useCallback**    | Fonksiyon referansını sabit tutar, child component’leri optimize eder |
| **Virtualization** | Büyük listelerde sadece görünür öğeleri render eder                   |
| **Profiler**       | Render sürelerini analiz eder ve optimizasyon noktalarını gösterir    |
