React’te form yönetimi başlangıçta basittir, ancak formlar büyüdükçe:

  • State yönetimi karmaşıklaşır
  • Validasyon kodları çoğalır
  • Performans sorunları ortaya çıkar

Formik ve Yup, bu sorunları çözmek için geliştirilmiştir.

1. Formik ve Yup Kurulumu

npm install formik yup

Formik → form state, submit ve validation yönetir
Yup → validation şemalarını tanımlar, Formik ile entegre çalışır

2. Basit Formik Formu

import React from "react";
import { Formik, Form, Field } from "formik";

function SimpleForm() {
  return (
    <Formik
      initialValues={{ name: "", email: "" }} // 🔹 Form başlangıç değerleri
      onSubmit={(values) => {
        console.log("Form gönderildi:", values);
      }}
    >
      {/* Form bileşeni */}
      <Form>
        <label>İsim:</label>
        <Field name="name" placeholder="İsminizi girin" />

        <label>Email:</label>
        <Field name="email" placeholder="Email girin" type="email" />

        <button type="submit">Gönder</button>
      </Form>
    </Formik>
  );
}

export default SimpleForm;
Field bileşeni form alanlarını Formik ile bağlar.
 onSubmit fonksiyonu form submit edildiğinde çalışır.

3. Yup ile Validation

Formik + Yup kombinasyonu ile validation kurallarını ekleyebiliriz.

import React from "react";
import { Formik, Form, Field, ErrorMessage } from "formik";
import * as Yup from "yup";

// Yup validation şeması
const validationSchema = Yup.object({
  name: Yup.string().required("İsim zorunludur"),
  email: Yup.string().email("Geçersiz email").required("Email zorunludur"),
  age: Yup.number()
    .min(18, "18 yaşından küçük olamazsınız")
    .required("Yaş zorunludur"),
});

function ValidatedForm() {
  return (
    <Formik
      initialValues={{ name: "", email: "", age: "" }}
      validationSchema={validationSchema} // Validation şeması eklenir
      onSubmit={(values) => console.log("Form değerleri:", values)}
    >
      <Form>
        <label>İsim:</label>
        <Field name="name" placeholder="İsminizi girin" />
        <ErrorMessage name="name" component="div" style={{ color: "red" }} />

        <label>Email:</label>
        <Field name="email" placeholder="Email girin" type="email" />
        <ErrorMessage name="email" component="div" style={{ color: "red" }} />

        <label>Yaş:</label>
        <Field name="age" type="number" placeholder="Yaşınızı girin" />
        <ErrorMessage name="age" component="div" style={{ color: "red" }} />

        <button type="submit">Gönder</button>
      </Form>
    </Formik>
  );
}

export default ValidatedForm;
ErrorMessage bileşeni validation hatalarını otomatik gösterir.
 Yup şeması ile kurallar merkezi ve okunabilir hâle gelir.

4. Dinamik Form Alanları

Formik ile array veya repeatable alanlar kolayca yönetilebilir.

import React from "react";
import { Formik, Form, Field, FieldArray } from "formik";

function DynamicForm() {
  return (
    <Formik
      initialValues={{ friends: [""] }} // Başlangıçta bir arkadaş alanı
      onSubmit={(values) => console.log(values)}
    >
      {({ values }) => (
        <Form>
          <FieldArray name="friends">
            {({ push, remove }) => (
              <div>
                {values.friends.map((_, index) => (
                  <div key={index}>
                    <Field name={`friends.${index}`} placeholder="Arkadaş adı" />
                    <button type="button" onClick={() => remove(index)}>
                      Sil
                    </button>
                  </div>
                ))}
                <button type="button" onClick={() => push("")}>
                  Yeni Arkadaş Ekle
                </button>
              </div>
            )}
          </FieldArray>
          <button type="submit">Gönder</button>
        </Form>
      )}
    </Formik>
  );
}

export default DynamicForm;

FieldArray ile dinamik alan ekleme ve silme işlemleri kolaylaşır.

5. Performans Optimizasyonu İpuçları

Formik büyük formlarda performans sorununa neden olabilir. İşte birkaç çözüm:

  1. FastField: Sadece ilgili alan değişirse render olur.
import { FastField } from "formik";
<FastField name="email" placeholder="Email" />

2. React.memo: Form bileşenlerini sarmak render’ı azaltır.

3. Yup.lazy: Karmaşık validation durumlarını optimize eder.

Özet

| Konu                  | Açıklama                                                 |
| --------------------- | -------------------------------------------------------- |
| **Formik**            | Form state, submit ve validation yönetimi sağlar         |
| **Field / FastField** | Form alanlarını Formik ile bağlar                        |
| **ErrorMessage**      | Validation hatalarını otomatik gösterir                  |
| **Yup**               | Validation şemalarını merkezi ve okunabilir hâle getirir |
| **FieldArray**        | Dinamik veya tekrar eden form alanları yönetir           |
