TypeScript, JavaScript üzerine inşa edilmiş bir statik tip sistemidir.
React ile birlikte kullanıldığında:

  • Hataları daha derleyici aşamasında yakalayabiliriz
  • Component’ler ve hook’lar daha öngörülebilir hale gelir
  • Büyük projelerde refactoring ve bakım kolaylaşır

1. TypeScript Kurulumu

Vite ile React + TS Projesi:

npm create vite@latest my-app -- --template react-ts
cd my-app
npm install
npm run dev
Artık proje .tsx uzantılı dosyalar ile çalışır ve TypeScript tip denetimi aktif olur.

2. Component Props Tipleri

Fonksiyon Component Örneği:

import React from "react";

// Props tipi tanımlanır
type ButtonProps = {
  label: string;
  onClick: () => void; // fonksiyon tipini belirtir
};

const Button: React.FC<ButtonProps> = ({ label, onClick }) => {
  return <button onClick={onClick}>{label}</button>;
};

export default Button;
  • Props tipleri sayesinde yanlış tipte değer göndermeye derleyici izin vermez.
  • React.FC generic ile component tipi belirtilir.

Kullanım:

<Button label="Gönder" onClick={() => console.log("Tıklandı")} />
Eğer label sayısal olsaydı TypeScript derleyicide hata verecekti.

3. useState Tipleri

import React, { useState } from "react";

function Counter() {
  // Tip belirtme
  const [count, setCount] = useState<number>(0);

  return (
    <div>
      <h2>Sayaç: {count}</h2>
      <button onClick={() => setCount(count + 1)}>Artır</button>
    </div>
  );
}

export default Counter;
  • useState’in generic tipi <number> ile state’in tipi belirlenir
  • Yanlış tip atamaları derleme sırasında yakalanır

4. useRef Tipleri

import React, { useRef } from "react";

function InputFocus() {
  // HTMLInputElement tipini verdik
  const inputRef = useRef<HTMLInputElement>(null);

  const handleClick = () => {
    inputRef.current?.focus(); // current nullable olduğu için ? kullandık
  };

  return (
    <div>
      <input ref={inputRef} placeholder="Adınızı girin" />
      <button onClick={handleClick}>Focus</button>
    </div>
  );
}

export default InputFocus;

useRef ile DOM elementlerini veya değerleri tip güvenli şekilde yönetebiliriz.

5. Generic Component Örneği

import React from "react";

// Generic component, tip parametresi ile çalışır
type ListProps<T> = {
  items: T[];
  render: (item: T) => JSX.Element;
};

function List<T>({ items, render }: ListProps<T>) {
  return <ul>{items.map((item, index) => <li key={index}>{render(item)}</li>)}</ul>;
}

export default List;

Kullanım:

<List
  items={["Elma", "Armut", "Muz"]}
  render={(item) => <span>{item}</span>}
/>

Generic component ile farklı tiplerde listeleri tek bir component ile render edebiliriz.

6. Context API ile Tip Güvenliği

import React, { createContext, useContext, useState } from "react";

// Context tipi tanımlanır
type AuthContextType = {
  isLoggedIn: boolean;
  login: () => void;
};

const AuthContext = createContext<AuthContextType | undefined>(undefined);

export const AuthProvider: React.FC<{ children: React.ReactNode }> = ({ children }) => {
  const [isLoggedIn, setIsLoggedIn] = useState(false);

  const login = () => setIsLoggedIn(true);

  return <AuthContext.Provider value={{ isLoggedIn, login }}>{children}</AuthContext.Provider>;
};

// Context hook’u
export const useAuth = () => {
  const context = useContext(AuthContext);
  if (!context) throw new Error("useAuth must be used within AuthProvider");
  return context;
};
  • Context ile global state tip güvenli olur
  • Yanlış kullanım derleme sırasında hata verir

Özet

| Konu                          | Açıklama                                               |
| ----------------------------- | ------------------------------------------------------ |
| **Props Tipleri**             | Component’lere gönderilen değerlerin tipi güvenli olur |
| **useState / useRef Tipleri** | State ve ref’ler tip güvenli şekilde yönetilir         |
| **Generic Component**         | Tek component ile farklı tipler işlenebilir            |
| **Context API**               | Global state tip güvenli ve predictable olur           |
| **React.FC ve JSX.Element**   | Component tipleri ve render tipleri belirlenir         |
