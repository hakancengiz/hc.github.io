useEffect ile Lifecycle Mantığı

React’te useEffect, component’in yaşam döngüsünü (lifecycle) yönetmek için kullanılır.
Yani component oluştuğunda, güncellendiğinde veya yok olduğunda çalışacak kodları tanımlayabiliriz.

Temel Kullanım

import { useEffect, useState } from "react";

function Timer() {
  const [count, setCount] = useState(0);

  // useEffect: component her render olduğunda çalışır
  useEffect(() => {
    console.log("Component render edildi.");
  });

  return (
    <div>
      <p>Sayım: {count}</p>
      <button onClick={() => setCount(count + 1)}>Arttır</button>
    </div>
  );
}

export default Timer;

Sadece İlk Render’da Çalıştırmak

useEffect(() => {
  console.log("Component sadece ilk render'da çalıştı!");
}, []); // boş dizi => sadece ilk kez render olduğunda tetiklenir

Cleanup (Temizlik İşlemi)

useEffect(() => {
  const interval = setInterval(() => {
    console.log("Zaman akıyor...");
  }, 1000);

  // Component yok olduğunda çalışır
  return () => {
    clearInterval(interval);
    console.log("Temizlik yapıldı.");
  };
}, []);
useEffect, class component’lerdeki componentDidMount, componentDidUpdate, componentWillUnmount işlevlerinin hook versiyonudur.

useRef ile DOM ve State Arasında Köprü

useRef, hem DOM elementlerine erişmek, hem de değerleri render olmadan saklamak için kullanılır.

1. DOM Elementine Erişim

import { useRef } from "react";

function FocusInput() {
  const inputRef = useRef(); // bir referans oluşturuyoruz

  const handleFocus = () => {
    inputRef.current.focus(); // referans üzerinden DOM'a erişiyoruz
  };

  return (
    <div>
      {/* ref attribute'u ile input'u referansa bağlıyoruz */}
      <input ref={inputRef} placeholder="Adınızı yazın" />
      <button onClick={handleFocus}>Odağı Ver</button>
    </div>
  );
}

export default FocusInput;

2. Render Olmadan Değer Saklamak

import { useEffect, useRef, useState } from "react";

function RenderCounter() {
  const [count, setCount] = useState(0);
  const renderCount = useRef(0); // state gibi ama render tetiklemez

  useEffect(() => {
    renderCount.current += 1; // sayacı her render'da arttır
  });

  return (
    <div>
      <p>Buton {count} kez tıklandı.</p>
      <p>Component {renderCount.current} kez render oldu.</p>
      <button onClick={() => setCount(count + 1)}>Tıkla</button>
    </div>
  );
}
useRef değiştiğinde component yeniden render edilmez — bu yönüyle useState’ten farklıdır.

useMemo ve useCallback

React, performans optimizasyonu için iki önemli hook sunar:

  • useMemo: hesaplanan değeri saklar
  • useCallback: fonksiyon referansını saklar

useMemo — Hesaplanan Değerleri Hatırlama

import { useMemo, useState } from "react";

function ExpensiveCalculation() {
  const [count, setCount] = useState(0);
  const [text, setText] = useState("");

  // ağır bir işlem simülasyonu
  const expensiveValue = useMemo(() => {
    console.log("Ağır işlem yapılıyor...");
    return count * 2; // örnek işlem
  }, [count]); // sadece count değiştiğinde yeniden hesaplanır

  return (
    <div>
      <h3>Sonuç: {expensiveValue}</h3>
      <button onClick={() => setCount(count + 1)}>Arttır</button>
      <input
        value={text}
        onChange={(e) => setText(e.target.value)}
        placeholder="Metin gir"
      />
    </div>
  );
}
useMemo, gereksiz hesaplamaları önleyerek render performansını artırır.

useCallback — Fonksiyon Referansını Hatırlama

import { useCallback, useState } from "react";

function Parent() {
  const [count, setCount] = useState(0);

  // useCallback sayesinde fonksiyon referansı sabit kalır
  const handleClick = useCallback(() => {
    console.log("Tıklandı!");
  }, []);

  return (
    <div>
      <button onClick={() => setCount(count + 1)}>Say: {count}</button>
      <Child onAction={handleClick} />
    </div>
  );
}

function Child({ onAction }) {
  console.log("Child render edildi!");
  return <button onClick={onAction}>Çocuk Buton</button>;
}

Custom Hook’lar: Tekrarlayan Mantıkları Soyutlama

Custom Hook’lar, birden fazla component’te tekrarlanan mantığı yeniden kullanılabilir hale getirir.
Kural olarak “use” ile başlamalıdır.

Örnek: Pencere boyutunu izleyen custom hook

import { useState, useEffect } from "react";

// Custom hook tanımı
function useWindowSize() {
  const [size, setSize] = useState({ width: window.innerWidth, height: window.innerHeight });

  useEffect(() => {
    // pencere boyutu değiştikçe state'i güncelle
    const handleResize = () => {
      setSize({ width: window.innerWidth, height: window.innerHeight });
    };

    window.addEventListener("resize", handleResize);

    // temizlik: event listener'ı kaldır
    return () => window.removeEventListener("resize", handleResize);
  }, []);

  return size; // dışa state döndürülür
}

// Custom hook kullanımı
function ShowWindowSize() {
  const { width, height } = useWindowSize(); // hook'tan değer alıyoruz

  return (
    <p>
      Genişlik: {width}px, Yükseklik: {height}px
    </p>
  );
}
useWindowSize, herhangi bir component içinde kolayca yeniden kullanılabilir hale gelir.

Context API ile Global State Yönetimi

Context API, component’lar arasında veri paylaşmak için prop drilling sorununu çözer.
Yani veriyi her seviye aşağıya props olarak göndermek zorunda kalmazsın.

Örnek: Tema Yönetimi

import { createContext, useContext, useState } from "react";

// 1. Context oluştur
const ThemeContext = createContext();

// 2. Provider component
function ThemeProvider({ children }) {
  const [theme, setTheme] = useState("light");

  const toggleTheme = () => setTheme(theme === "light" ? "dark" : "light");

  return (
    // context provider ile veriyi çocuklara aktarıyoruz
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

// 3. Context kullanan component
function ThemeButton() {
  const { theme, toggleTheme } = useContext(ThemeContext); // context'ten veri çek
  return (
    <button onClick={toggleTheme}>
      Şu anki tema: {theme === "light" ? "Açık" : "Koyu"}
    </button>
  );
}

// 4. Uygulama yapısı
function App() {
  return (
    <ThemeProvider>
      <ThemeButton />
    </ThemeProvider>
  );
}

export default App;
useContext, component’ların global verilere erişimini kolaylaştırır.
 Küçük ölçekli projelerde Redux’a gerek kalmadan state paylaşımı sağlar.

Özet

| Hook            | Görevi                                  |
| --------------- | --------------------------------------- |
| **useEffect**   | Component yaşam döngüsünü yönetir       |
| **useRef**      | DOM veya sabit değer referansları tutar |
| **useMemo**     | Hesaplanan değerleri cache’ler          |
| **useCallback** | Fonksiyon referansını cache’ler         |
| **Custom Hook** | Tekrarlayan mantıkları soyutlar         |
| **Context API** | Global state paylaşımı sağlar           |
