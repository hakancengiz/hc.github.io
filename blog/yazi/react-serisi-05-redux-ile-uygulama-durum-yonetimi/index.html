1. Redux Nedir ve Neden Kullanılır?

React’te küçük projelerde state ve props yeterlidir.
Ancak uygulama büyüdükçe, component’lar arası veri akışı karışmaya başlar.

Redux bu sorunu çözer:

Tüm uygulama state’ini merkezi bir “store” içinde toplar.

Yani:

  • Veriler component’lar arasında props zinciriyle dolaşmaz.
  • Uygulamanın durumu (state) tek bir yerden kontrol edilir.
  • Değişiklikler predictable (öngörülebilir) hale gelir.

Redux veri akışı şu şekildedir:

Component → Action → Reducer → Store → Component

Yani component bir “action” tetikler, reducer bunu işler, store güncellenir ve component yeniden render olur.

2. Redux Toolkit: Modern Redux Yaklaşımı

Eskiden Redux kullanmak için çok fazla boilerplate (tekrar eden kod) gerekiyordu.
Redux Toolkit (RTK) bu süreci sadeleştirir.
Artık createSlice, configureStore gibi fonksiyonlarla birkaç satırda yapı kurulur.

Kurulum

npm install @reduxjs/toolkit react-redux

Basit Sayaç (Counter) Örneği

store.js;

import { configureStore, createSlice } from "@reduxjs/toolkit";

// createSlice, hem state'i hem reducer'ları aynı yerde tanımlar
const counterSlice = createSlice({
  name: "counter", // slice adı
  initialState: { value: 0 }, // başlangıç state
  reducers: {
    increment: (state) => {
      // Immer sayesinde state doğrudan değiştirilebilir gibi yazılır
      state.value += 1;
    },
    decrement: (state) => {
      state.value -= 1;
    },
    reset: (state) => {
      state.value = 0;
    },
  },
});

// Action creator'ları dışa aktar
export const { increment, decrement, reset } = counterSlice.actions;

// Store'u oluştur
export const store = configureStore({
  reducer: {
    counter: counterSlice.reducer,
  },
});

App.jsx;

import { Provider, useDispatch, useSelector } from "react-redux";
import { store, increment, decrement, reset } from "./store";

function Counter() {
  // useSelector: store'daki state'e erişim sağlar
  const value = useSelector((state) => state.counter.value);

  // useDispatch: action'ları tetiklemek için kullanılır
  const dispatch = useDispatch();

  return (
    <div style={{ textAlign: "center", marginTop: "30px" }}>
      <h2>Redux Sayaç</h2>
      <h3>Değer: {value}</h3>

      {/* Action'ları dispatch ile gönderiyoruz */}
      <button onClick={() => dispatch(increment())}>Artır</button>
      <button onClick={() => dispatch(decrement())}>Azalt</button>
      <button onClick={() => dispatch(reset())}>Sıfırla</button>
    </div>
  );
}

// Provider, tüm uygulamayı Redux store'a bağlar
export default function App() {
  return (
    <Provider store={store}>
      <Counter />
    </Provider>
  );
}

Çalışma Mantığı:

Kullanıcı butona bastığında bir action dispatch edilir → reducer çalışır → store güncellenir → component yeniden render olur.

3. Async İşlemler: createAsyncThunk ile API Entegrasyonu

Gerçek uygulamalarda veriler genellikle API’lerden çekilir.
Bu noktada Redux Toolkit’in createAsyncThunk fonksiyonu devreye girer.

userSlice.js;

import { createSlice, createAsyncThunk } from "@reduxjs/toolkit";
import axios from "axios";

// createAsyncThunk: async işlemleri (örneğin API çağrısı) yönetir
export const fetchUsers = createAsyncThunk("users/fetchUsers", async () => {
  const res = await axios.get("https://jsonplaceholder.typicode.com/users");
  return res.data; // otomatik olarak payload olarak döner
});

const userSlice = createSlice({
  name: "users",
  initialState: {
    data: [],
    loading: false,
    error: null,
  },
  extraReducers: (builder) => {
    // API isteği başladı
    builder.addCase(fetchUsers.pending, (state) => {
      state.loading = true;
    });

    // API isteği başarılı
    builder.addCase(fetchUsers.fulfilled, (state, action) => {
      state.loading = false;
      state.data = action.payload;
    });

    // API isteği hata verdi
    builder.addCase(fetchUsers.rejected, (state, action) => {
      state.loading = false;
      state.error = action.error.message;
    });
  },
});

export default userSlice.reducer;

store.js;

import { configureStore } from "@reduxjs/toolkit";
import userReducer from "./userSlice";

// Store içerisine reducer ekleniyor
export const store = configureStore({
  reducer: {
    users: userReducer,
  },
});

App.jsx

import { Provider, useDispatch, useSelector } from "react-redux";
import { store } from "./store";
import { fetchUsers } from "./userSlice";
import { useEffect } from "react";

function Users() {
  const dispatch = useDispatch();

  // State'i useSelector ile okuyoruz
  const { data, loading, error } = useSelector((state) => state.users);

  // Component yüklendiğinde kullanıcıları getir
  useEffect(() => {
    dispatch(fetchUsers());
  }, [dispatch]);

  if (loading) return <p>Yükleniyor...</p>;
  if (error) return <p>Hata: {error}</p>;

  return (
    <ul>
      {data.slice(0, 5).map((u) => (
        <li key={u.id}>{u.name}</li>
      ))}
    </ul>
  );
}

export default function App() {
  return (
    <Provider store={store}>
      <h2>Kullanıcı Listesi (Redux + Async Thunk)</h2>
      <Users />
    </Provider>
  );
}

Bu örnekle birlikte:
Redux artık sadece “state tutan” bir yapı değil, aynı zamanda asenkron veri yönetiminde de etkili bir araç haline gelir.

4. Middleware, DevTools ve Debugging

Redux Toolkit, geliştirici deneyimini kolaylaştırmak için birçok araç içerir:

Middleware

  • Her action dispatch edildiğinde araya girip işlem yapabilir.
  • Örneğin: loglama, auth kontrolü, hata yakalama.
const loggerMiddleware = (store) => (next) => (action) => {
  console.log("Action:", action.type);
  next(action);
};
export const store = configureStore({
  reducer: { users: userReducer },
  middleware: (getDefault) => getDefault().concat(loggerMiddleware),
});

Redux DevTools

Tarayıcı eklentisi olarak kurulur →
Her state değişikliğini, action’ı ve payload’ı görsel olarak izleyebilirsin.

// Redux Toolkit DevTools otomatik aktif gelir.
// Ekstra ayar yapmana gerek yok.

5. Gerçek Uygulama Örneği: Mini Kullanıcı Yönetimi

Artık her şeyi birleştirelim.
Aşağıda Redux Toolkit + Async Thunk + API çağrısı ile küçük bir uygulama oluşturuyoruz.

import { useEffect, useState } from "react";
import { useDispatch, useSelector } from "react-redux";
import { fetchUsers } from "./userSlice";

// Kullanıcı yönetimi component'i
export function UserManager() {
  const dispatch = useDispatch();
  const { data, loading } = useSelector((state) => state.users);
  const [filter, setFilter] = useState("");

  useEffect(() => {
    dispatch(fetchUsers());
  }, [dispatch]);

  // Filtreleme işlemi
  const filtered = data.filter((u) =>
    u.name.toLowerCase().includes(filter.toLowerCase())
  );

  return (
    <div style={{ margin: "20px" }}>
      <h3>Redux Toolkit Kullanıcı Yönetimi</h3>
      <input
        placeholder="İsim filtrele..."
        value={filter}
        onChange={(e) => setFilter(e.target.value)}
      />

      {loading ? (
        <p>Yükleniyor...</p>
      ) : (
        <ul>
          {filtered.slice(0, 5).map((u) => (
            <li key={u.id}>{u.name}</li>
          ))}
        </ul>
      )}
    </div>
  );
}
