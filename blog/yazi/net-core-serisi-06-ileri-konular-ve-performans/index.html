Uygulama büyüdükçe sorunlar da büyür:

  • Sorgular yavaşlar
  • Gereksiz bellek kullanımı oluşur
  • Servis bağımlılıkları artar

Bu yazıda, .NET Core’da performansı artırmak için kullanabileceğin
en etkili teknikleri adım adım işleyeceğiz.

1. Asenkron (Async/Await) Operasyonlar

Problem: Uzun süren işlemler (örneğin veritabanı veya API çağrıları), thread’i bloke eder.
Çözüm: async ve await ile bu işlemleri non-blocking hale getirmek.

// Business/Services/UserService.cs
// Asenkron çalışan kullanıcı servis örneği
public class UserService : IUserService
{
    private readonly IUserRepository _userRepository;

    // Repository bağımlılığı constructor ile alınır
    public UserService(IUserRepository userRepository)
    {
        _userRepository = userRepository;
    }

    // Asenkron çalışan metot: thread bloke etmez
    public async Task<List<User>> GetAllUsersAsync()
    {
        // Veritabanı sorgusunu asenkron çalıştırır
        var users = await _userRepository.GetAllAsync();

        // Listeyi geri döner
        return users;
    }
}

Avantaj:

  • Thread boşa çıkar, başka istekleri işleyebilir.
  • Özellikle yüksek trafikli API’lerde scalability (ölçeklenebilirlik) artar.

2. Caching (Bellek Tabanlı Önbellekleme)

Amaç: Sık erişilen veriyi bellekte tutarak veritabanı yükünü azaltmak.

MemoryCache Kullanımı

// Business/Services/ProductService.cs
// Ürün listesini önbelleğe alan servis sınıfı
public class ProductService : IProductService
{
    private readonly IProductRepository _productRepository;
    private readonly IMemoryCache _cache;

    public ProductService(IProductRepository productRepository, IMemoryCache cache)
    {
        _productRepository = productRepository;
        _cache = cache;
    }

    public async Task<List<Product>> GetAllProductsAsync()
    {
        // 1️⃣ Cache içinde "products" anahtarı var mı kontrol edilir
        if (_cache.TryGetValue("products", out List<Product> cachedProducts))
        {
            // 2️⃣ Cache varsa doğrudan onu döner (veritabanına gitmez)
            return cachedProducts;
        }

        // 3️⃣ Yoksa veritabanından veri çekilir
        var products = await _productRepository.GetAllAsync();

        // 4️⃣ Veri cache'e eklenir (5 dakikalık ömür)
        _cache.Set("products", products, TimeSpan.FromMinutes(5));

        return products;
    }
}

Not:

  • Küçük ölçekli uygulamalarda MemoryCache idealdir.
  • Büyük sistemlerde Redis gibi dağıtık cache’ler tercih edilir.

3. Redis Cache (Dağıtık Önbellek)

Çoklu sunucu ortamında (load balancing) MemoryCache yeterli olmaz.
Bu durumda Redis kullanılır.

// Program.cs
builder.Services.AddStackExchangeRedisCache(options =>
{
    // Redis bağlantı adresi
    options.Configuration = "localhost:6379";
    options.InstanceName = "MyAppCache_";
});

Kullanımı:

// Business/Services/UserService.cs
public class UserService : IUserService
{
    private readonly IUserRepository _userRepository;
    private readonly IDistributedCache _cache;

    public UserService(IUserRepository userRepository, IDistributedCache cache)
    {
        _userRepository = userRepository;
        _cache = cache;
    }

    public async Task<List<User>> GetCachedUsersAsync()
    {
        // 1️⃣ Cache'te veri var mı kontrol edilir
        var cachedData = await _cache.GetStringAsync("users");
        if (!string.IsNullOrEmpty(cachedData))
        {
            // 2️⃣ Cache’te varsa deserialize edilip döner
            return JsonSerializer.Deserialize<List<User>>(cachedData);
        }

        // 3️⃣ Yoksa DB’den veri alınır
        var users = await _userRepository.GetAllAsync();

        // 4️⃣ JSON’a çevrilip cache’e eklenir
        var jsonData = JsonSerializer.Serialize(users);
        await _cache.SetStringAsync("users", jsonData,
            new DistributedCacheEntryOptions { AbsoluteExpirationRelativeToNow = TimeSpan.FromMinutes(10) });

        return users;
    }
}

Avantaj:

  • Tüm sunucular aynı cache’i kullanır.
  • Performans dramatik şekilde artar.

4. Dependency Injection (DI) Optimizasyonu

Fazla Transient servis kullanımı, gereksiz nesne üretimi anlamına gelir.
Bu da CPU ve GC yükünü artırır.

| Lifetime      | Ne Zaman Oluşur    | Kullanım                         |
| ------------- | ------------------ | -------------------------------- |
| **Transient** | Her çağrıda        | Hafif, kısa ömürlü servisler     |
| **Scoped**    | Her HTTP isteğinde | Web API servisleri               |
| **Singleton** | Uygulama boyunca   | Log, Cache gibi kalıcı servisler |

Örnek:

builder.Services.AddSingleton<ILogger, FileLogger>();
builder.Services.AddScoped<IUserService, UserService>();
builder.Services.AddTransient<IEmailService, EmailService>();

Gereksiz yere Transient kullanmak, performansı ciddi düşürür.

5. Logging (Performans Analizi İçin)

Uygulamanın performansını izlemek için loglama şarttır.
ASP.NET Core’da yerleşik ILogger arayüzü bulunur.

// Business/Services/OrderService.cs
public class OrderService : IOrderService
{
    private readonly ILogger<OrderService> _logger;

    public OrderService(ILogger<OrderService> logger)
    {
        _logger = logger;
    }

    public void CreateOrder(Order order)
    {
        try
        {
            _logger.LogInformation("Sipariş oluşturuluyor...");

            // İş mantığı
            // ...

            _logger.LogInformation("Sipariş başarıyla oluşturuldu.");
        }
        catch (Exception ex)
        {
            // Hataları loglar
            _logger.LogError(ex, "Sipariş oluşturulurken hata oluştu!");
        }
    }
}

Not: LogInformation, LogWarning, LogError seviyeleri sayesinde loglar kolay filtrelenebilir.

6. Entity Framework Performans İpuçları

Gereksiz sorgulardan kaçın

// Kötü: Tüm tabloyu çekiyor
var users = _context.Users.ToList();

// İyi: Sadece ihtiyacın olan alanı çek
var names = _context.Users.Select(u => u.Name).ToList();

Lazy Loading yerine Eager Loading kullan

// Gereksiz sorgular açabilir
var orders = _context.Orders.ToList();

// Daha verimli: Include ile ilişkili veriyi tek sorguda çek
var orders = _context.Orders.Include(o => o.Customer).ToList();

AsNoTracking kullan (Okuma senaryolarında)

var products = _context.Products
    .AsNoTracking() // EF değişiklikleri izlemez → daha hızlı
    .ToList();

Middleware Performans Takibi

İstek süresini ölçmek için özel middleware ekleyebilirsin;

// Middleware/RequestTimingMiddleware.cs
public class RequestTimingMiddleware
{
    private readonly RequestDelegate _next;
    private readonly ILogger<RequestTimingMiddleware> _logger;

    public RequestTimingMiddleware(RequestDelegate next, ILogger<RequestTimingMiddleware> logger)
    {
        _next = next;
        _logger = logger;
    }

    public async Task InvokeAsync(HttpContext context)
    {
        var stopwatch = Stopwatch.StartNew();

        // Sonraki middleware'e geç
        await _next(context);

        stopwatch.Stop();
        _logger.LogInformation($"İstek süresi: {stopwatch.ElapsedMilliseconds} ms");
    }
}

Kaydet:

// Program.cs
app.UseMiddleware<RequestTimingMiddleware>();

Bu sayede her API isteğinin çalışma süresini loglayabilirsin.

8. Garbage Collector (GC) ve Bellek Yönetimi

C# otomatik bellek yönetimi sunsa da, bazı hatalı kullanımlar performansı etkiler.

Kaçınılması gereken durumlar

  • Gereksiz büyük nesne oluşturmak (örneğin her istek için 100MB list)
  • IDisposable nesneleri using bloğu olmadan bırakmak
  • Static değişkenlerde referansları temizlememek

Öneri:

// IDisposable örnek
using (var stream = new FileStream("log.txt", FileMode.Create))
{
    // İşlem tamamlanınca otomatik dispose edilir
}

9. Parallel ve Background Services

CPU-bound işlemler için Parallel.ForEach veya BackgroundService kullanılabilir.

// Services/ReportService.cs
// Raporlama işlemini arka planda çalıştıran servis
public class ReportBackgroundService : BackgroundService
{
    private readonly ILogger<ReportBackgroundService> _logger;

    public ReportBackgroundService(ILogger<ReportBackgroundService> logger)
    {
        _logger = logger;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            _logger.LogInformation("Rapor servisi çalışıyor...");

            // Ağır raporlama işlemleri burada yapılır
            await Task.Delay(TimeSpan.FromMinutes(5), stoppingToken);
        }
    }
}

Kayıt:

builder.Services.AddHostedService<ReportBackgroundService>();
