“Bende Çalışıyor” Problemini Bitiren Teknoloji: Docker Nedir?

docker·14 Nisan 2026·~3 dk okuma

Modern yazılım geliştirme süreçlerinde “çalışıyor ama benim bilgisayarımda” problemi en sık karşılaşılan sorunlardan biridir. Docker bu problemi çözmek için geliştirilmiş bir teknolojidir.

Docker, uygulamaları “container (konteyner / izole çalışma ortamı)” içinde çalıştırmanı sağlar. Bu sayede uygulama, hangi ortamda çalışırsa çalışsın aynı şekilde davranır.

Docker Ne İşe Yarar?

Docker’ın temel amacı şudur:

  • Uygulamayı bağımlılıklarıyla birlikte paketlemek
  • Her ortamda aynı şekilde çalışmasını sağlamak
  • Sistemler arasında taşınabilirliği artırmak
  • Kurulum ve dağıtım süreçlerini kolaylaştırmak

Özetle Docker, “çalışma ortamını uygulamanın içine taşır”.

Container (Konteyner) Nedir?

Container, uygulamanın çalışması için gereken her şeyi içinde barındıran izole bir ortamdır.

Bunlar:

  • Kod
  • Runtime (çalışma zamanı)
  • Sistem kütüphaneleri
  • Bağımlılıklar

Container’lar hafiftir çünkü tam bir işletim sistemi içermezler. Sadece gerekli parçaları kullanırlar.

Virtual Machine (Sanal Makine) ile Farkı

Sanal makine (VM — Virtual Machine) tam bir işletim sistemi çalıştırır.

Container ise:

  • Host işletim sistemini paylaşır
  • Daha hızlı başlar
  • Daha az kaynak kullanır

Kısaca:

  • VM = Ağır, tam sistem
  • Container = Hafif, izole uygulama ortamı

Docker Image (Görüntü) Nedir?

Image (imaj), bir container’ın şablonudur.

Yani:

  • Uygulama nasıl çalışacak?
  • Hangi bağımlılıklar var?
  • Hangi ortam hazırlanmalı?

Bunların hepsi image içinde tanımlıdır.

Image’lar değiştirilemez (read-only) yapıdadır.

Container vs Image

  • Image = Plan / şablon
  • Container = Çalışan uygulama

Bir image’dan birçok container oluşturabilirsin.

Docker Kurulumu ve Kontrol

Docker kurulduktan sonra terminalden kontrol edebilirsin:

docker --version
# Docker'ın yüklü olup olmadığını ve versiyonunu gösterir

docker info
# Sistemle ilgili detaylı Docker bilgilerini listeler

İlk Container Çalıştırma

Basit bir örnek:

docker run hello-world
# Docker'ın düzgün çalışıp çalışmadığını test eden örnek container'ı çalıştırır

Bu komut:

  • Image yoksa indirir
  • Container oluşturur
  • Çalıştırır
  • Sonucu ekrana basar

Dockerfile Nedir?

Dockerfile, bir Docker image oluşturmak için yazılan talimat dosyasıdır.

Örnek:

# Base image (temel imaj)
FROM mcr.microsoft.com/dotnet/aspnet:8.0
# Uygulamanın çalışacağı temel ortamı belirler

WORKDIR /app
# Container içinde çalışma dizinini belirler

COPY . .
# Projedeki tüm dosyaları container içine kopyalar

RUN dotnet restore
# Proje bağımlılıklarını yükler

RUN dotnet build -c Release
# Projeyi build eder (derler)

ENTRYPOINT ["dotnet", "MyApp.dll"]
# Container çalıştığında çalışacak ana komutu belirtir

Docker Image Build Etme

Dockerfile üzerinden image oluşturmak:

docker build -t myapp:1.0 .
# -t: image adı ve versiyon etiketi
# . : Dockerfile'ın bulunduğu dizin

Container Çalıştırma

Oluşturulan image ile container başlatma:

docker run -d -p 8080:80 myapp:1.0
# -d: detached (arka planda çalıştır)
# -p: port eşleştirme (host:container)
# 8080:80 -> dışarıdan 8080, container içinde 80

Çalışan Container’ları Görme

docker ps
# Şu anda çalışan container'ları listeler

docker ps -a
# Tüm container'ları (çalışan + duran) gösterir

Container Durdurma ve Silme

docker stop <container_id>
# Çalışan container'ı durdurur

docker rm <container_id>
# Container'ı sistemden siler

Docker Compose Nedir?

Birden fazla container’ı yönetmek için kullanılır.

Örneğin:

  • Web uygulaması
  • Veritabanı
  • Cache servisi

Hepsini tek dosyada yönetebilirsin.

Örnek docker-compose.yml:

version: "3.8"

services:
  web:
    image: myapp:1.0
    ports:
      - "8080:80"
    # Web uygulamasını 8080 portundan dış dünyaya açar

  db:
    image: postgres:16
    environment:
      POSTGRES_PASSWORD: example
    # PostgreSQL veritabanı container'ı

Çalıştırma:

docker-compose up -d
# Tüm servisleri arka planda başlatır

Docker Kullanırken Dikkat Edilmesi Gerekenler

  • Her şeyi tek image içine koyma (modüler ol)
  • Gereksiz dosyaları image’a dahil etme
  • Küçük base image kullan (performans için)
  • Secret (şifre) bilgilerini image içine yazma
  • Log ve monitoring sistemleri kullan

Docker, modern yazılım geliştirme ve deployment süreçlerinde standart haline gelmiş güçlü bir teknolojidir. Özellikle mikroservis mimarisi, CI/CD süreçleri ve bulut sistemlerinde kritik rol oynar.
