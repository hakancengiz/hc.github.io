Test yazmak, React projelerinde kod kalitesini ve sürdürülebilirliği artırır.
React Testing Library (RTL) ve Jest bu işi kolaylaştırır.

1. Kurulum

npm install --save-dev @testing-library/react @testing-library/jest-dom jest

Jest → test runner ve assertion kütüphanesi
React Testing Library → React component’lerini gerçek DOM benzeri ortamda test eder
jest-dom → ekstra matcher’lar sağlar (ör: toBeInTheDocument())

2. Basit Component Testi

Önce basit bir component oluşturalım:

// Hello.jsx
import React from "react";

function Hello({ name }) {
  return <h1>Merhaba, {name}!</h1>;
}

export default Hello;

render → component’i DOM’a render eder
screen → test ortamında DOM elemanlarını bulmamızı sağlar
expect(...).toBeInTheDocument() → jest-dom matcher ile doğrulama

3. Event Testi (Buton Click)

// Counter.jsx
import React, { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h2>Sayaç: {count}</h2>
      <button onClick={() => setCount(count + 1)}>Artır</button>
    </div>
  );
}

export default Counter;
// Counter.test.jsx
import { render, screen, fireEvent } from "@testing-library/react";
import Counter from "./Counter";

test("Sayaç butona basıldığında artıyor", () => {
  render(<Counter />);
  
  const button = screen.getByText("Artır");
  fireEvent.click(button); // Butona tıklama simülasyonu

  expect(screen.getByText("Sayaç: 1")).toBeInTheDocument(); // Doğrulama
});

fireEvent.click(button) → kullanıcı etkileşimi simülasyonu

4. Mock API Çağrısı Testi

Bazen component API çağrısı yapar. Bunu mock ile test edebiliriz.

// UserList.jsx
import React, { useEffect, useState } from "react";

function UserList() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    fetch("/api/users")
      .then((res) => res.json())
      .then((data) => setUsers(data));
  }, []);

  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}

export default UserList;

Test dosyası:

// UserList.test.jsx
import { render, screen, waitFor } from "@testing-library/react";
import UserList from "./UserList";

// Fetch’i mock’layalım
global.fetch = jest.fn(() =>
  Promise.resolve({
    json: () => Promise.resolve([{ id: 1, name: "Hakan" }]),
  })
);

test("UserList API verisini render ediyor", async () => {
  render(<UserList />);

  // async işlem tamamlanana kadar bekle
  await waitFor(() => {
    expect(screen.getByText("Hakan")).toBeInTheDocument();
  });
});

global.fetch = jest.fn(...) → fetch çağrısını taklit eder
waitFor → async işlemin bitmesini bekler

5. Snapshot Testleri

Component’in render çıktısını kayıt edip değişiklikleri takip etmek için kullanılır.

import { render } from "@testing-library/react";
import Hello from "./Hello";

test("Hello snapshot testi", () => {
  const { asFragment } = render(<Hello name="Hakan" />);
  expect(asFragment()).toMatchSnapshot(); // DOM snapshot’ını kaydeder
});

Kod değişirse snapshot testleri uyarı verir ve farkı gösterir.

Özet

| Konu              | Açıklama                                                            |
| ----------------- | ------------------------------------------------------------------- |
| **render**        | Component’i test ortamına render eder                               |
| **screen**        | DOM üzerinde element bulmayı sağlar                                 |
| **fireEvent**     | Kullanıcı etkileşimi simülasyonu yapar                              |
| **waitFor**       | Async işlemler için bekleme sağlar                                  |
| **jest.fn()**     | Fonksiyon veya API çağrılarını mock’lar                             |
| **Snapshot Test** | Component’in render çıktısını kaydeder ve değişiklikleri takip eder |
