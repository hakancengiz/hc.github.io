1. Fetch API / Axios ile Veri Çekme

React’te dış bir API’den veri almak için genellikle iki popüler yöntem vardır:

  • Fetch API (tarayıcıda gömülü gelir)
  • Axios (daha gelişmiş bir kütüphane)

Fetch API ile Veri Çekme

import { useEffect, useState } from "react";

function FetchExample() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    // API'den veri çekme işlemi
    fetch("https://jsonplaceholder.typicode.com/users")
      .then((response) => response.json()) // gelen veriyi JSON'a çeviriyoruz
      .then((data) => setUsers(data)) // state'e aktarıyoruz
      .catch((error) => console.error("Veri alınırken hata:", error));
  }, []);

  return (
    <div>
      <h3>Kullanıcı Listesi (Fetch)</h3>
      <ul>
        {users.map((u) => (
          <li key={u.id}>{u.name}</li>
        ))}
      </ul>
    </div>
  );
}

export default FetchExample;

Axios ile Veri Çekme

import axios from "axios";
import { useEffect, useState } from "react";

function AxiosExample() {
  const [posts, setPosts] = useState([]);

  useEffect(() => {
    // Axios ile veri çekme
    axios
      .get("https://jsonplaceholder.typicode.com/posts")
      .then((res) => setPosts(res.data))
      .catch((err) => console.error("Axios hatası:", err));
  }, []);

  return (
    <div>
      <h3>Gönderiler (Axios)</h3>
      <ul>
        {posts.slice(0, 5).map((p) => (
          <li key={p.id}>{p.title}</li>
        ))}
      </ul>
    </div>
  );
}

export default AxiosExample;
Axios, Fetch’e göre hata yönetimi, interceptors, timeout gibi özelliklerde daha avantajlıdır.

2. CRUD İşlemleri: Tam Uygulama Örneği

Aşağıda basit bir “Kullanıcı Yönetimi” uygulaması yapıyoruz.
Veriler JSONPlaceholder API’sinden alınacak ve Create, Read, Update, Delete işlemleri Axios ile yapılacak.

import { useEffect, useState } from "react";
import axios from "axios";

function UserCrudApp() {
  const [users, setUsers] = useState([]);
  const [newUser, setNewUser] = useState("");
  const [editingUser, setEditingUser] = useState(null);

  // Kullanıcıları yükle
  useEffect(() => {
    getUsers();
  }, []);

  const getUsers = () => {
    axios.get("https://jsonplaceholder.typicode.com/users").then((res) => {
      setUsers(res.data);
    });
  };

  // Yeni kullanıcı ekle (CREATE)
  const addUser = () => {
    axios
      .post("https://jsonplaceholder.typicode.com/users", { name: newUser })
      .then((res) => {
        setUsers([...users, res.data]);
        setNewUser("");
      });
  };

  // Kullanıcıyı sil (DELETE)
  const deleteUser = (id) => {
    axios
      .delete(`https://jsonplaceholder.typicode.com/users/${id}`)
      .then(() => setUsers(users.filter((u) => u.id !== id)));
  };

  // Kullanıcıyı düzenle (UPDATE)
  const updateUser = (id) => {
    axios
      .put(`https://jsonplaceholder.typicode.com/users/${id}`, { name: editingUser.name })
      .then((res) => {
        setUsers(users.map((u) => (u.id === id ? res.data : u)));
        setEditingUser(null);
      });
  };

  return (
    <div>
      <h3>Kullanıcı Yönetimi</h3>

      {/* Yeni kullanıcı ekleme alanı */}
      <input
        value={newUser}
        onChange={(e) => setNewUser(e.target.value)}
        placeholder="Yeni kullanıcı adı"
      />
      <button onClick={addUser}>Ekle</button>

      <ul>
        {users.slice(0, 5).map((u) => (
          <li key={u.id}>
            {editingUser?.id === u.id ? (
              <>
                {/* Düzenleme modu */}
                <input
                  value={editingUser.name}
                  onChange={(e) => setEditingUser({ ...editingUser, name: e.target.value })}
                />
                <button onClick={() => updateUser(u.id)}>Kaydet</button>
              </>
            ) : (
              <>
                {u.name}
                <button onClick={() => setEditingUser(u)}>Düzenle</button>
                <button onClick={() => deleteUser(u.id)}>Sil</button>
              </>
            )}
          </li>
        ))}
      </ul>
    </div>
  );
}

export default UserCrudApp;
Bu örnekte API sahte olsa da, mantık aynıdır:
GET, POST, PUT, DELETE — CRUD işlemlerinin temeli.

3. React Query (TanStack Query) ile Veri Yönetimi

React Query, veri çekme işlemlerini önbelleğe alma (caching), otomatik yeniden fetch etme, loading/hata yönetimi gibi kolaylıklarla optimize eder.

Kurulum

npm install @tanstack/react-query

Örnek Kullanım

import { useQuery } from "@tanstack/react-query";
import axios from "axios";

function ReactQueryExample() {
  // useQuery: veriyi cache'li ve otomatik yönetir
  const { data, isLoading, isError } = useQuery({
    queryKey: ["posts"], // 🔹 cache anahtarı
    queryFn: () => axios.get("https://jsonplaceholder.typicode.com/posts").then((res) => res.data),
  });

  if (isLoading) return <p>Yükleniyor...</p>;
  if (isError) return <p>Bir hata oluştu.</p>;

  return (
    <div>
      <h3>React Query ile Gönderiler</h3>
      <ul>
        {data.slice(0, 5).map((post) => (
          <li key={post.id}>{post.title}</li>
        ))}
      </ul>
    </div>
  );
}

export default ReactQueryExample;
React Query, veri çekme mantığını useEffect + useState kombinasyonundan çok daha verimli hale getirir.

4. State Yönetiminde Redux veya Zustand Kullanımı

React Query uzak (server) veriyi yönetirken,
Redux veya Zustand genellikle uygulama içi (client) state yönetiminde kullanılır.

Redux Toolkit (Modern Redux)

npm install @reduxjs/toolkit react-redux
// store.js
import { configureStore, createSlice } from "@reduxjs/toolkit";

// slice: state + reducer'ı birleştirir
const counterSlice = createSlice({
  name: "counter",
  initialState: { value: 0 },
  reducers: {
    increment: (state) => { state.value += 1 },
    decrement: (state) => { state.value -= 1 },
  },
});

export const { increment, decrement } = counterSlice.actions;
export const store = configureStore({ reducer: { counter: counterSlice.reducer } });
// App.jsx
import { Provider, useDispatch, useSelector } from "react-redux";
import { store, increment, decrement } from "./store";

function Counter() {
  const value = useSelector((state) => state.counter.value);
  const dispatch = useDispatch();

  return (
    <div>
      <p>Sayım: {value}</p>
      <button onClick={() => dispatch(increment())}>+</button>
      <button onClick={() => dispatch(decrement())}>-</button>
    </div>
  );
}

export default function App() {
  return (
    <Provider store={store}>
      <Counter />
    </Provider>
  );
}

Zustand — Minimalist Alternatif

npm install zustand
import { create } from "zustand";

// store oluşturuluyor
const useStore = create((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  decrement: () => set((state) => ({ count: state.count - 1 })),
}));

function CounterZustand() {
  const { count, increment, decrement } = useStore();

  return (
    <div>
      <p>Sayım: {count}</p>
      <button onClick={increment}>+</button>
      <button onClick={decrement}>-</button>
    </div>
  );
}

export default CounterZustand;
Zustand, Redux’un sadeleştirilmiş halidir — özellikle küçük projelerde tercih edilir.

5. LocalStorage ve SessionStorage Kullanımı

React’te bu yapılar, kullanıcı verilerini tarayıcıda kalıcı olarak saklamak için kullanılır.

LocalStorage Örneği

import { useEffect, useState } from "react";

function LocalStorageExample() {
  const [name, setName] = useState("");

  useEffect(() => {
    // Sayfa yenilendiğinde kayıtlı isim varsa al
    const saved = localStorage.getItem("username");
    if (saved) setName(saved);
  }, []);

  const saveName = () => {
    localStorage.setItem("username", name); // kalıcı olarak sakla
  };

  return (
    <div>
      <input
        value={name}
        onChange={(e) => setName(e.target.value)}
        placeholder="İsmini gir"
      />
      <button onClick={saveName}>Kaydet</button>
    </div>
  );
}

export default LocalStorageExample;

SessionStorage Örneği

// Oturum boyunca saklanır, sekme kapatılınca silinir
sessionStorage.setItem("theme", "dark");
console.log(sessionStorage.getItem("theme")); // "dark"
