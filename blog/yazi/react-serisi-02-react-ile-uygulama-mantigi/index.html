Props ve State Arasındaki Fark

React’te iki temel veri taşıma mekanizması vardır: props ve state.
İkisi de component içinde veri tutar ama amaçları farklıdır.

| Özellik              | Props                   | State               |
| -------------------- | ----------------------- | ------------------- |
| Değiştirilebilir mi? | ❌ Hayır (readonly)     | ✅ Evet             |
| Nerede tanımlanır?   | Parent component’ta     | Component içinde    |
| Ne için kullanılır?  | Dışarıdan veri almak    | İç veri tutmak      |
| Örnek Kullanım       | `UserCard name="Hakan"` | `useState("Hakan")` |

Örnek

// Parent component
function App() {
  return <UserCard name="Hakan" age={29} />;
}

// Child component
function UserCard({ name, age }) {
  return (
    <div>
      <h3>{name}</h3>
      <p>Yaş: {age}</p>
    </div>
  );
}

Burada App, UserCard’a props gönderiyor.
Eğer bu veriler kullanıcı etkileşimiyle değişecekse, state kullanılmalıdır:

function Counter() {
  const [count, setCount] = useState(0);
  return (
    <button onClick={() => setCount(count + 1)}>Tıklandı: {count}</button>
  );
}

Conditional Rendering (Koşullu Gösterim)

Uygulamalarda bazen veriye veya duruma göre farklı component’lar göstermek gerekir.
React bunu “if”, “ternary” veya “short-circuit” ifadeleriyle çözer.

Örnek 1 — Basit Koşul

function Greeting({ isLoggedIn }) {
  return (
    <div>
      {isLoggedIn ? <h2>Hoş geldin!</h2> : <h2>Lütfen giriş yap.</h2>}
    </div>
  );
}

Örnek 2 — Short-Circuit Kullanımı

function Alert({ message }) {
  return <>{message && <div className="alert">{message}</div>}</>;
}

Bu şekilde message boşsa <div> hiç render edilmez.

Listeler ve Key Mantığı

React, dizilerden otomatik olarak liste render edebilir.
Ancak her eleman benzersiz bir key değeri taşımalıdır — bu, React’in Virtual DOM’daki farkları takip etmesini sağlar.

Örnek

function TodoList() {
  const todos = ["Alışveriş yap", "Egzersiz yap", "Kod yaz"];
  
  return (
    <ul>
      {todos.map((todo, index) => (
        <li key={index}>{todo}</li>
      ))}
    </ul>
  );
}

Not: Eğer veriler benzersiz kimlik (id) içeriyorsa index yerine onu kullanmak daha sağlıklıdır.

<li key={todo.id}>{todo.text}</li>

Form Yönetimi ve Controlled Components

React’te formlar “controlled” olarak yönetilir.
Yani input’un değeri doğrudan state tarafından kontrol edilir.

Örnek — Tek Input

import { useState } from "react";

function NameForm() {
  const [name, setName] = useState("");

  function handleChange(e) {
    setName(e.target.value);
  }

  return (
    <form>
      <input type="text" value={name} onChange={handleChange} />
      <p>Merhaba, {name || "Ziyaretçi"}!</p>
    </form>
  );
}

Örnek — Çoklu Form Alanı

function ContactForm() {
  const [form, setForm] = useState({ name: "", email: "" });

  function handleChange(e) {
    setForm({ ...form, [e.target.name]: e.target.value });
  }

  function handleSubmit(e) {
    e.preventDefault();
    console.log(form);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input name="name" placeholder="Ad" onChange={handleChange} />
      <input name="email" placeholder="E-posta" onChange={handleChange} />
      <button type="submit">Gönder</button>
    </form>
  );
}
Controlled form yaklaşımı sayesinde input değerleri her zaman component’in state’iyle senkronizedir.

React’te Styling Yaklaşımları

React, stilleri yönetmek için birçok farklı yaklaşımı destekler.
İhtiyaca göre basit veya modüler bir yöntem seçebilirsin.

1. Inline CSS

function Box() {
  return <div style={{ backgroundColor: "lightblue", padding: 10 }}>Kutu</div>;
}

2. CSS Dosyası (Klasik)

import "./App.css";

function App() {
  return <h1 className="title">Merhaba React</h1>;
}

3. CSS Modules

import styles from "./Card.module.css";

function Card() {
  return <div className={styles.container}>Kart</div>;
}

Card.module.css;

.container {
  background: white;
  border-radius: 12px;
}

4. Styled Components

npm install styled-components
import styled from "styled-components";

const Button = styled.button`
  background: #0078d4;
  color: white;
  padding: 10px 20px;
  border-radius: 8px;
`;

function App() {
  return <Button>Kaydet</Button>;
}

5. Tailwind CSS (Modern Yaklaşım)

Tailwind, utility-class temelli bir CSS framework’tür.
Kurulum sonrası doğrudan HTML benzeri sınıflarla çalışılır:

<button className="bg-blue-500 text-white px-4 py-2 rounded">
  Kaydet
</button>

Özet

| Konu                      | Ana Fikir                                            |
| ------------------------- | ---------------------------------------------------- |
| **Props**                 | Dışarıdan alınan, değiştirilemeyen veriler           |
| **State**                 | Component içinde değişebilen veriler                 |
| **Conditional Rendering** | Veriye göre farklı içerik göstermek                  |
| **Listeler**              | Map + Key yapısı ile render edilir                   |
| **Formlar**               | State ile kontrol edilen controlled components       |
| **Stiller**               | Inline, CSS Modules, Styled Components veya Tailwind |
