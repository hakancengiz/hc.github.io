1. Proje Oluşturma ve Başlangıç Ayarları

.NET projesinin temeli, doğru yapılandırma ile atılır. Program.cs dosyası, uygulamanın servislerinin (DI) ve HTTP istek hattının (middleware) yapılandırıldığı merkezi noktadır.

Authentication Tipi (Individual):

Bu seçenek, projenize ASP.NET Core Identity altyapısını otomatik olarak ekler. Kullanıcı kaydı, girişi, parola yönetimi gibi özellikler için hazır bir temel sunar.

Container Support (Docker):

Bu özellik, uygulamanızın bir Docker konteyneri içinde çalışabilmesi için gerekli olan Dockerfile’ı projenize ekler. Bu, uygulamanızın farklı ortamlarda (geliştirme, test, production) tutarlı bir şekilde çalışmasını sağlar.

Razor Runtime Compilation

Geliştirme sürecinde .cshtml dosyalarında yaptığınız değişikliklerin, projeyi yeniden başlatmadan tarayıcıda anında görünmesini sağlar. Bu, UI geliştirme hızını önemli ölçüde artırır.

Örnek: Program.cs Başlangıç Yapılandırması

// Uygulama oluşturucusunu (builder) başlatır.
// Bu nesne üzerinden servisler ve yapılandırmalar eklenir.
var builder = WebApplication.CreateBuilder(args);

// Servis koleksiyonuna MVC (Model-View-Controller) yapısını ve
// Razor view'lerinin anlık derlenmesi özelliğini ekler.
builder.Services.AddControllersWithViews()
 .AddRazorRuntimeCompilation(); // Sadece geliştirme ortamında kullanılması önerilir.

// Builder'dan uygulama nesnesini (app) oluşturur.
// Bu noktadan sonra middleware'ler yapılandırılır.
var app = builder.Build();

// HTTP isteklerini HTTPS'e yönlendirir. Güvenlik için önemlidir.
app.UseHttpsRedirection();

// wwwroot klasöründeki statik dosyaların (css, js, img) sunulmasını sağlar.
app.UseStaticFiles();

// Gelen isteğin hangi Controller/Action'a gideceğini belirleyen
yönlendirme altyapısını aktif eder.
app.UseRouting();

// Kimlik doğrulama ve yetkilendirme mekanizmalarını devreye alır.
app.UseAuthorization();

// Varsayılan URL rotasını tanımlar:
/{controller=Home}/{action=Index}/{id?}
app.MapDefaultControllerRoute();

// Uygulamayı çalıştırır ve gelen istekleri dinlemeye başlar.
app.Run();

2. Controllers, IActionResult ve View Eşlemesi

Controller’lar, gelen istekleri işleyen ve kullanıcıya bir yanıt (genellikle bir View) döndüren sınıflardır.

IActionResult, bir Action metodunun döndürebileceği farklı sonuç türlerini (View, JSON, Not Found, Redirect vb.) temsil eden bir arayüzdür.

Örnek: Basit ProductController Action’ları

using Microsoft.AspNetCore.Mvc;
using Microsoft.EntityFrameworkCore;
using System.Linq;

public class ProductController : Controller
{
    // Dependency Injection ile veritabanı context'ini alır.
    // 'readonly' olması, sadece constructor'da atanabileceği anlamına gelir.
    private readonly NWContext _ctx;

    // Constructor Injection: Program.cs'de kaydedilen NWContext servisi buraya enjekte edilir.
    public ProductController(NWContext ctx)
    {
        _ctx = ctx;
    }

    public IActionResult Index()
    {
        // Veritabanından tüm ürünleri çeker ve listeye dönüştürür.
        var list = _ctx.Products.ToList();

        // Modeli (list) ilgili View'e gönderir.
        // Varsayılan olarak Views/Product/Index.cshtml aranır.
        return View(list);
    }

    public IActionResult Details(int id)
    {
        // İlgili ürünü ve tedarikçi bilgisini "eager loading" ile tek sorguda getirir.
        // Bu, N+1 sorgu problemini engeller.
        var p = _ctx.Products
                    .Include(p => p.Supplier)
                    .FirstOrDefault(x => x.ProductId == id);

        // Ürün bulunamazsa HTTP 404 Not Found durum kodunu döndürür.
        if (p == null) return NotFound();

        // Entity'yi doğrudan View'e göndermek yerine bir ViewModel'e mapleyerek göndeririz.
        // Bu, en iyi pratiklerden biridir.
        return View(new ProductViewModel(p));
    }
}

3. Program.cs — Uygulama Kalbi

.NET 6 ve sonrası “Minimal APIs” yaklaşımı ile Program.cs, uygulamanın tüm başlangıç yapılandırmasını tek bir dosyada toplar.

Middleware’lerin sırası çok önemlidir çünkü her biri bir sonraki adımı etkiler.

Örnek: Servis ve Middleware Kayıtları

var builder = WebApplication.CreateBuilder(args);

// Session (Oturum) yönetimini DI container'a ekler.
builder.Services.AddSession(options =>
{
    // Oturumun ne kadar süre boşta kalabileceğini belirtir.
    options.IdleTimeout = TimeSpan.FromMinutes(30);
    // Cookie'nin sadece sunucu tarafından okunmasını sağlar (güvenlik).
    options.Cookie.HttpOnly = true;
});

// Entity Framework Core DbContext'ini DI container'a kaydeder.
// AddDbContext, varsayılan olarak Scoped bir yaşam süresi kullanır.
builder.Services.AddDbContext<NWContext>(options =>
    options.UseSqlServer(decryptedConnectionString)
);

// HttpContext'e dışarıdan erişim sağlamak için IHttpContextAccessor'ı kaydeder.
builder.Services.AddHttpContextAccessor();

var app = builder.Build();

// ... Diğer middleware'ler ...

// Session middleware'ini HTTP pipeline'ına ekler.
// UseRouting'den sonra, UseAuthorization'dan önce gelmelidir.
app.UseSession();

// Kimlik doğrulama (Authentication) middleware'ini ekler.
app.UseAuthentication();

// Yetkilendirme (Authorization) middleware'ini ekler.
app.UseAuthorization();

// ...

4. Razor Syntax ve @ Kullanımı

Razor, C# kodunu HTML ile iç içe yazmayı sağlayan bir “view engine”dir. @ sembolü, C# kodunun başlangıcını belirtir.

Örnek: Razor Sözdizimi

@{
    // Bu bir C# kod bloğudur.
    var x = 5;
    var message = "Merhaba Dünya";
}

<!-- Değişkenin değerini HTML içine yazar. -->
<p>Value: @x</p>

<!-- '@:' ifadesi, bir satırlık düz metin çıktısı verir ve Razor'un
     HTML etiketlerini yanlış yorumlamasını engeller. -->
@:Bu bir düz metin satırıdır.

<!-- C# ifadesinin sonucunu parantez içinde yazdırır. -->
<p>Mesajınız: @(message.ToUpper())</p>

Tip güvenliği (type safety) olmadığı ve Redirect sonrası veriyi korumadıkları için genellikle ViewModel’ler veya TempData tercih edilir.

7. Formlar, Model Binding ve DataAnnotations

Model Binding:

HTTP isteğiyle gelen verilerin, Action metodunun parametresi olan bir nesnenin (ViewModel) özellikleriyle otomatik eşleştirilmesidir.

DataAnnotations:

Modelin özelliklerine eklenen ve doğrulama kurallarını (zorunlu alan, uzunluk vb.) tanımlayan özniteliklerdir.

ViewModel:

Sadece View’in ihtiyaç duyduğu verileri içeren sınıflardır. Entity’leri doğrudan View’e göndermek güvenlik ve esneklik açısından önerilmez.

ProductViewModel Örneği

// Models/ProductViewModel.cs
using System.ComponentModel;
using System.ComponentModel.DataAnnotations;

public class ProductViewModel
{
    public int ProductId { get; set; }

    [DisplayName("Ürün Adı")]
    [Required(ErrorMessage = "Ürün adı alanı boş bırakılamaz.")]
    [StringLength(50)]
    public string ProductName { get; set; }

    public ProductViewModel() { }

    public ProductViewModel(Product p)
    {
        ProductId = p.ProductId;
        ProductName = p.ProductName;
    }

    public Product ConvertToEntity() => new Product
    {
        ProductId = this.ProductId,
        ProductName = this.ProductName,
    };
}

Controller Create Action Örneği

// Controllers/ProductController.cs
[HttpPost]
[ValidateAntiForgeryToken]
public IActionResult Create(ProductViewModel model)
{
    // DataAnnotations ile tanımlanan kurallara göre modelin geçerli olup olmadığını kontrol eder.
    if (!ModelState.IsValid)
    {
        return View(model);
    }

    var entity = model.ConvertToEntity();
    _ctx.Products.Add(entity);
    int res = _ctx.SaveChanges();

    if (res > 0)
        return RedirectToAction("Index");

    ModelState.AddModelError("", "Kayıt işlemi sırasında bir hata oluştu.");
    return View(model);
}

8. Custom `ValidationAttribute` Örneği

Mevcut doğrulama kurallarının yetersiz kaldığı durumlarda, `ValidationAttribute` sınıfından miras alarak kendi özel doğrulama kurallarınızı oluşturabilirsiniz.

SubeCheckerAttribute Örneği

using System.ComponentModel.DataAnnotations;

public class SubeCheckerAttribute : ValidationAttribute
{
    protected override ValidationResult IsValid(object value, ValidationContext validationContext)
    {
        var s = value as string;
        if (string.IsNullOrWhiteSpace(s) || !IsValidBranch(s))
        {
            return new ValidationResult(ErrorMessage ?? "Geçersiz şube kodu girdiniz.");
        }
        return ValidationResult.Success;
    }

    private bool IsValidBranch(string branchCode)
    {
        return branchCode.StartsWith("SUB");
    }
}

11. ProductController — CRUD Örnekleri

CRUD (Create, Read, Update, Delete) operasyonları, web uygulamalarının temelini oluşturur.

CRUD Action’ları

// Index (Listeleme) - Sayfalama ile
public IActionResult Index(int page = 1)
{
    int pageSize = 10;
    var list = _ctx.Products
                   .Include(p => p.Category)
                   .OrderBy(p => p.ProductId)
                   .Skip((page - 1) * pageSize)
                   .Take(pageSize)
                   .Select(p => new ProductViewModel(p))
                   .ToList();

    return View(list);
}

// Update (Güncelleme)
[HttpPost]
[ValidateAntiForgeryToken]
public IActionResult Update(ProductViewModel model)
{
    if (!ModelState.IsValid) 
        return View(model);

    var entity = model.ConvertToEntity();
    _ctx.Products.Update(entity);

    if (_ctx.SaveChanges() > 0)
    {
        TempData["Sonuc"] = "Ürün başarıyla güncellendi.";
    }

    return RedirectToAction("Index");
}

// Delete (Silme)
[HttpPost]
[ValidateAntiForgeryToken]
public IActionResult Delete(int id)
{
    var item = _ctx.Products.Find(id);
    if (item == null) 
        return NotFound();

    _ctx.Products.Remove(item);

    if (_ctx.SaveChanges() > 0)
    {
        TempData["Sonuc"] = "Ürün başarıyla silindi.";
    }

    return RedirectToAction("Index");
}

12. ViewModel — Entity Mapping

Bu desen, uygulamanın veritabanı katmanı (Entity) ile sunum katmanı (View) arasında bir ayrım sağlar.

Bu, güvenlik, esneklik ve bakım kolaylığı açısından kritik öneme sahiptir.

Detaylı ProductViewModel

public class ProductViewModel
{
    public int ProductId { get; set; }
    public string ProductName { get; set; }
    public decimal? UnitPrice { get; set; }
    public short? UnitsInStock { get; set; }
    public int? CategoryId { get; set; }
    public string CategoryName { get; set; }

    public ProductViewModel() { }

    // Constructor Mapping: Entity'den ViewModel'e.
    public ProductViewModel(Product entity)
    {
        ProductId = entity.ProductId;
        ProductName = entity.ProductName;
        UnitPrice = entity.UnitPrice;
        UnitsInStock = entity.UnitsInStock;
        CategoryId = entity.CategoryId;
        CategoryName = entity.Category?.CategoryName;
    }

    // Metot Mapping: ViewModel'den Entity'ye.
    public Product ConvertToEntity() => new Product
    {
        ProductId = this.ProductId,
        ProductName = this.ProductName,
        UnitPrice = this.UnitPrice,
        UnitsInStock = this.UnitsInStock,
        CategoryId = this.CategoryId
    };
}

14. Sayfalama: TagHelper ile Component Hale Getirme

TagHelper’lar, Razor view’lerinde yeniden kullanılabilir, sunucu taraflı bileşenler oluşturmak için güçlü bir yoldur.

PagingTagHelper Örneği

using Microsoft.AspNetCore.Razor.TagHelpers;
using System.Text;

[HtmlTargetElement("paging")]
public class PagingTagHelper : TagHelper
{
    [HtmlAttributeName("for-PageIndex")]
    public int PageIndex { get; set; }

    [HtmlAttributeName("for-PageCount")]
    public int PageCount { get; set; }

    [HtmlAttributeName("for-ControllerName")]
    public string ControllerName { get; set; }

    [HtmlAttributeName("for-ActionName")]
    public string ActionName { get; set; }

    public override void Process(TagHelperContext context, TagHelperOutput output)
    {
        var sb = new StringBuilder();
        sb.AppendLine("<nav><ul class='pagination'>");

        for (int i = 1; i <= PageCount; i++)
        {
            var active = i == PageIndex ? "active" : "";
            sb.AppendLine($@"
                <li class='page-item {active}'>
                    <a class='page-link' href='/{ControllerName}/{ActionName}?page={i}'>{i}</a>
                </li>");
        }

        sb.AppendLine("</ul></nav>");

        output.TagName = null;
        output.Content.SetHtmlContent(sb.ToString());
    }
}

15. Session, Cookies ve Sepet (Cart) Yönetimi

  • Session: Sunucu tarafında, kullanıcıya özel olarak saklanan veridir.
  • Cookie: Kullanıcının tarayıcısında saklanan küçük metin dosyalarıdır.

Session ile Sepet Yönetimi

// Sepet modeli (basit)
public class SepetModel
{
    public int ProductId { get; set; }
    public int Adet { get; set; }
}

// Sepete Ekleme Action'ı
public IActionResult AddToCart(int productId, int adet)
{
    var sepetJson = HttpContext.Session.GetString("Sepetim");

    var sepet = string.IsNullOrEmpty(sepetJson)
        ? new List<SepetModel>()
        : JsonSerializer.Deserialize<List<SepetModel>>(sepetJson);

    var mevcutUrun = sepet.FirstOrDefault(s => s.ProductId == productId);

    if (mevcutUrun != null)
    {
        mevcutUrun.Adet += adet;
    }
    else
    {
        sepet.Add(new SepetModel { ProductId = productId, Adet = adet });
    }

    HttpContext.Session.SetString("Sepetim", JsonSerializer.Serialize(sepet));

    return RedirectToAction("Index");
}

@using System.Text.Json
@using MyApp.Models
@inject IHttpContextAccessor accessor

@{
    var session = accessor.HttpContext.Session;
    var urunSayisi = 0;

    if (session.IsAvailable && session.Keys.Any(k => k == "Sepetim"))
    {
        var sepetJson = session.GetString("Sepetim");
        if (!string.IsNullOrEmpty(sepetJson))
        {

        }
    }
}

19. UserController, UserManager ve SignInManager Kullanımı

  • UserManager: Kullanıcı oluşturma, silme, rol atama gibi işlemleri yönetir.
  • SignInManager: Kullanıcı girişi, çıkışı gibi oturum işlemlerini yönetir.

Kayıt (Register) Action Örneği

[HttpPost]
public async Task<IActionResult> Register(UserViewModel model)
{
    if (!ModelState.IsValid) 
        return View(model);

    var user = new User 
    { 
        UserName = model.UserName, 
        Email = model.Email 
    };

    var result = await _userManager.CreateAsync(user, model.Password);

    if (result.Succeeded)
    {
        await _signInManager.SignInAsync(user, isPersistent: false);
        return RedirectToAction("Index", "Home");
    }

    foreach (var error in result.Errors)
    {
        ModelState.AddModelError("", error.Description);
    }

    return View(model);
}

    }

21. TempData ile Redirect Sonrası Mesaj Gösterme

TempData, bir istekten hemen sonraki tek bir istek boyunca veriyi saklar. “PostRedirect-Get” deseninde kullanıcıya mesaj göstermek için idealdir.

Controller Action Örneği

[HttpPost]
public IActionResult Update(MyViewModel model)
{
    // ... güncelleme işlemleri ...

    TempData["SuccessMessage"] = "İşlem başarıyla tamamlandı!";
    return RedirectToAction("Index");
}

View Örneği (`_Layout.cshtml`)

@if (TempData["SuccessMessage"] != null)

    <div class="alert alert-success">@TempData["SuccessMessage"]</div>
}

22. SaveChanges() Dönüş Değeri

SaveChanges() metodu, veritabanında etkilenen (eklenen, güncellenen, silinen) satır sayısını int olarak döndürür.

Bu değer, işlemin başarılı olup olmadığını kontrol etmek için kullanılabilir. Ancak en güvenilir yöntem, DbUpdateException gibi istisnaları trycatch ile yakalamaktır.

Try-Catch ile Kullanım

try
{
    int affectedRows = _ctx.SaveChanges();
    if (affectedRows > 0)
    {
        // Başarılı
    }
}
catch (DbUpdateException ex)
{
    // Hata yönetimi, loglama vb.
}

23. Web API Projesi ve Swagger (OpenAPI)

Web API: Genellikle JSON formatında veri döndüren, UI içermeyen HTTP servisleridir.

  • ApiController: API controller’ları için varsayılan davranışları etkinleştirir.
  • Swagger (OpenAPI): API’nizin belgelenmesini ve tarayıcı üzerinden test edilmesini sağlayan bir araçtır.

CustomerApiController Örneği

using Microsoft.AspNetCore.Mvc;

[ApiController]
[Route("custapi")]
public class CustomerApiController : ControllerBase
{
    private readonly NWContext _ctx;

    public CustomerApiController(NWContext ctx)
    {
        _ctx = ctx;
    }

    [HttpGet]
    public IActionResult GetAll() => Ok(_ctx.Customers.ToList());

    [HttpGet("{id}")]
    public IActionResult GetById(string id)
    {
        var customer = _ctx.Customers.Find(id);
        if (customer == null) 
            return NotFound();

        return Ok(customer);
    }

    [HttpPost]
    public IActionResult Create([FromBody] Customer customer)
    {
        _ctx.Customers.Add(customer);
        _ctx.SaveChanges();
        return StatusCode(201, customer);
    }
}

24. Client (MVC) — ApiProvider ve HttpClientFactory

IHttpClientFactory: .NET Core’da HttpClient nesnelerini yönetmenin en doğru yoludur. Soket tüketimi gibi yaygın sorunları önler.

ApiProvider Örneği

using System.Net.Http;
using System.Net.Http.Json;
using System.Threading.Tasks;
using System.Collections.Generic;

public class ApiProvider
{
    private readonly IHttpClientFactory _httpClientFactory;
    private readonly string _baseUrl = "https://localhost:5001/";

    public ApiProvider(IHttpClientFactory httpClientFactory)
    {
        _httpClientFactory = httpClientFactory;
    }

    public async Task<List<T>> GetService<T>(string address) where T : class
    {
        var client = _httpClientFactory.CreateClient();
        client.BaseAddress = new Uri(_baseUrl);

        var response = await client.GetAsync(address);

        if (response.IsSuccessStatusCode)
        {
            return await response.Content.ReadFromJsonAsync<List<T>>();
        }

        return new List<T>();
    }
}

25. Activator.CreateInstance ile Runtime’da Nesne Oluşturma

Bu metot, bir tipin (Type) adını kullanarak çalışma zamanında (runtime) o tipten bir nesne örneği oluşturmanızı sağlar.

Kullanım Örneği

// T tipinin parametresiz bir constructor'ı olmalıdır.
T obj = Activator.CreateInstance<T>();

// Veya Type nesnesi üzerinden oluşturma
object productObj = Activator.CreateInstance(typeof(Product));

26. DI Registration ve Scoped ApiProvider Örneği

Servis kaydederken, lambda ifadesi kullanarak kaydı özelleştirebilir ve IConfiguration gibi başka servislerden değerler alabilirsiniz.

Program.cs Örneği

builder.Services.AddScoped<IProvider, ApiProvider>(sp =>
{
    var factory = sp.GetRequiredService<IHttpClientFactory>();
    var config = sp.GetRequiredService<IConfiguration>();
    string apiUrl = config.GetValue<string>("ApiSettings:BaseUrl");

    return new ApiProvider(factory) { ServerAddress = apiUrl };
});

28. ApiProvider — POST/PUT/DELETE Örnekleri

Bu metotlar, API’ye veri gönderme, güncelleme ve silme işlemlerini gerçekleştirir.

public async Task<bool> PostService<T>(string address, T model) where T : class
{
    var client = GetClient();
    var response = await client.PostAsJsonAsync(address, model);
    return response.IsSuccessStatusCode;
}

public async Task<bool> PutService<T>(string address, int id, T model) where T : class
{
    var client = GetClient();
    var response = await client.PutAsJsonAsync($"{address}/{id}", model);
    return response.IsSuccessStatusCode;
}

public async Task<bool> DeleteService(string address, int id)
{
    var client = GetClient();
    var response = await client.DeleteAsync($"{address}/{id}");
    return response.IsSuccessStatusCode;
}

29. JWT Authentication — Sunucu Tarafı (API)

JWT (JSON Web Token): Taraflar arasında güvenli bir şekilde bilgi aktarımını sağlayan bir standarttır. API’leri güvence altına almak için yaygın olarak kullanılır.

Program.cs JWT Yapılandırması

using Microsoft.AspNetCore.Authentication.JwtBearer;
using Microsoft.IdentityModel.Tokens;
using System.Text;

var key = Encoding.UTF8.GetBytes(builder.Configuration["Jwt:Key"]);

builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuer = false,
            ValidateAudience = false,
            ValidateLifetime = true,
            ValidateIssuerSigningKey = true,
            IssuerSigningKey = new SymmetricSecurityKey(key),
            ClockSkew = TimeSpan.Zero
        };
    });

30. ApiUserService — Token Üretimi

Kullanıcı adı ve parola ile giriş yapan kullanıcıya, başarılı olması durumunda bir JWT döndürülür.

using System.IdentityModel.Tokens.Jwt;
using System.Security.Claims;
using System.Text;
using Microsoft.IdentityModel.Tokens;

public async Task<string> ApiLoginAsync(string username, string password)
{
    var result = await _signInManager.PasswordSignInAsync(username, password, false, false);
    if (!result.Succeeded) 
        return null;

    var claims = new[] { new Claim(ClaimTypes.Name, username) };
    var key = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(_configuration["Jwt:Key"]));
    var creds = new SigningCredentials(key, SecurityAlgorithms.HmacSha256);

    var tokenDescriptor = new SecurityTokenDescriptor
    {
        Subject = new ClaimsIdentity(claims),
        Expires = DateTime.UtcNow.AddHours(3),
        SigningCredentials = creds
    };

    var tokenHandler = new JwtSecurityTokenHandler();
    var token = tokenHandler.CreateToken(tokenDescriptor);

    return tokenHandler.WriteToken(token);
}

31. Client: Token Alma ve Sonraki İsteklerde Kullanma

Client, API’den aldığı token’ı sonraki isteklerde Authorization başlığına eklemelidir.

using System.Net.Http.Headers;

// Token'ı aldıktan sonra session'a kaydetme
HttpContext.Session.SetString("JwtToken", token);

// Sonraki isteklerde token'ı header'a ekleme
private HttpClient GetClientWithToken()
{
    var client = _httpClientFactory.CreateClient();
    var token = _httpContextAccessor.HttpContext.Session.GetString("JwtToken");

    if (!string.IsNullOrEmpty(token))
    {
        client.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", token);
    }

    return client;
}

33. Localization (Yerelleştirme)

Uygulamanızın birden fazla dili desteklemesini sağlar. Metinler genellikle .resx uzantılı kaynak dosyalarında tutulur.

  • AddLocalization: Yerelleştirme servislerini DI container’a ekler.
  • UseRequestLocalization: Tarayıcı dil tercihlerine göre uygulamanın kültürünü ayarlayan middleware’i pipeline’a ekler.

Program.cs Yerelleştirme Yapılandırması

using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Localization;
using System.Globalization;

// 1. Yerelleştirme servislerini ekle ve kaynak dosyalarının yolunu belirt.
// "Resources" klasörü, projenin kök dizininde yer almalıdır.
builder.Services.AddLocalization(options => options.ResourcesPath = "Resources");

// 2. Desteklenecek dilleri ve kültürleri tanımla.
var supportedCultures = new[]
{
    new CultureInfo("tr-TR"),
    new CultureInfo("en-US")
};

// 3. Yerelleştirme seçeneklerini yapılandır.
var localizationOptions = new RequestLocalizationOptions()
    // Hiçbir dil belirtilmezse varsayılan olarak bu kültürü kullan.
    .SetDefaultCulture(supportedCultures[0].Name)
    // Uygulamanın desteklediği kültürleri listeye ekle.
    .AddSupportedCultures(supportedCultures.Select(c => c.Name).ToArray())
    // UI için desteklenen kültürleri listeye ekle (genellikle aynıdır).
    .AddSupportedUICultures(supportedCultures.Select(c => c.Name).ToArray());

var app = builder.Build();
// ...

// 4. Yapılandırılan seçeneklerle yerelleştirme middleware'ini pipeline'a ekle.
// Bu, UseRouting'den önce gelmelidir.
app.UseRequestLocalization(localizationOptions);
// ...
